# Vertical and Detached Layouts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver PRD task 8.2.2 with two reusable, accessible, tenant-aware workspace shells.

**Architecture:** Keep navigation and clinic authorization server-side; reuse shared partials between vertical and detached shells. Add local Alpine.js only for progressive mobile drawer behavior and a two-step server-confirmed clinic switch.

**Tech Stack:** Django 6.1 templates/session/auth, Python 3.14, Alpine.js 3.14.1, Sliced semantic assets, pytest, browser verification.

## Global Constraints

- User-facing copy is PT-BR; backend code and contracts are en-US.
- Every authenticated workspace request requires an active authorized clinic.
- No clinical/demo data, external JS/CSS CDN, or sensitive local storage.
- TDD precedes implementation; PRD is marked only after full gates.
